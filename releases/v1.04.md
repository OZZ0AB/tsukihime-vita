# Tsukihime Vita 1.04

A native PS Vita homebrew port for the original Tsukihime English release, built with VitaSDK and ONScripter-JH.

## Included

- Native Vita runtime loading the original ONScripter script and archives.
- English save/load menus and readable date/time fields.
- A fallback save timestamp if clock information is invalid.
- Checked save writes and startup logging.
- Custom bubble icon and LiveArea artwork.

Gameplay and saving have been confirmed working on a Vita. Not every route and scene has been exhaustively tested.

## Install

1. Install `TsukihimeVita-01.04.vpk` with VitaShell.
2. Copy your compatible English game files into `ux0:data/tsukihime/game/`:
   `nscript.dat`, `arc.nsa`, `arc.sar`, `arc1.nsa`, and `default.ttf`.
3. For background music, copy `track01.ogg` through `track10.ogg` into the `CD/` subdirectory.
4. Launch Tsukihime. To save, choose a slot in the in-game Save menu and confirm **Yes**.

Install over the existing Tsukihime bubble when upgrading. Saves reside in `ux0:data/tsukihime/save/`.

## Release files

- `TsukihimeVita-01.04.vpk`: installable application.
- `TsukihimeVita-01.04-source.tar.gz`: corresponding port source and build instructions.
- `SHA256SUMS`: SHA-256 checksums for the VPK and source archive.

The game script, archives, English translation, font, and music are not included. Supply the files from your own compatible copy. See the repository README for controls, troubleshooting, credits, and licensing.
