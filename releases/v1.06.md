# Tsukihime Vita 1.06

The Vita L trigger now cycles through four dialogue text sizes: original, approximately 12% larger, 24% larger, 35% larger, then back to original.

## Changes

- Replace L's instant-page-display shortcut with the text-size cycle.
- Show the selected size in the bottom margin and apply it on the next text page, keeping the page currently being read intact.
- Adjust line width and page height for each enlarged size, retaining word wrapping and adding page pauses before text would overflow.
- Keep menus, choice buttons, and backlog at their original size.
- Keep the selected size for the current app session; restarting the app restores the original size.
- Retain the save fixes, English word wrapping, and custom LiveArea artwork from previous releases.

The native VPK build and host checks for the four-step cycle, layout bounds, and text preservation across additional pages passed. The new L-trigger behavior still needs confirmation on a Vita; earlier gameplay, saving, and the 1.05 word-wrap update were confirmed working on hardware.

## Install or update

Install `TsukihimeVita-01.06.vpk` with VitaShell over the existing Tsukihime bubble. The title ID remains `TSUKI0001`. Existing game data and saves remain in `ux0:data/tsukihime/`.

While reading dialogue, press and release **L** to select a size. The bottom-margin notice confirms the selection. Advance to the next text page to see the selected size. Longer passages may require additional page advances at larger sizes.

For a first installation, copy your compatible mirror moon English game files into `ux0:data/tsukihime/game/`: `nscript.dat`, `arc.nsa`, `arc.sar`, `arc1.nsa`, and `default.ttf`. For background music, put `track01.ogg` through `track10.ogg` in the `CD/` subdirectory. See the repository README for full installation instructions and controls.
