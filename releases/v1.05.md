# Tsukihime Vita 1.05

English dialogue now wraps at spaces so words that fit on a line are no longer split at the right edge of the text area.

## Changes

- Move the next word to a new line when it will not fit in the remaining space.
- Preserve deliberate script line breaks, click waits, page changes, and indentation.
- Retain automatic word breaks in backlog and saved-page text.
- Keep character wrapping as a fallback for words longer than an entire line.
- Retain the save fixes and custom bubble and LiveArea artwork from 1.04.

The word-wrap update has been confirmed working on a Vita. Host layout checks covered 66,279 ordinary ASCII dialogue lines from the compatible English script. These checks complement hardware testing; every route and scene has not been exhaustively tested.

## Install or update

Install `TsukihimeVita-01.05.vpk` with VitaShell over the existing Tsukihime bubble. The title ID remains `TSUKI0001`. Existing game data and saves remain in `ux0:data/tsukihime/`.

For a first installation, copy your compatible mirror moon English game files into `ux0:data/tsukihime/game/`: `nscript.dat`, `arc.nsa`, `arc.sar`, `arc1.nsa`, and `default.ttf`. For background music, put `track01.ogg` through `track10.ogg` in the `CD/` subdirectory. See the repository README for the complete layout, controls, and troubleshooting.

## Release files

- `TsukihimeVita-01.05.vpk`: installable application.
- `TsukihimeVita-01.05-source.tar.gz`: corresponding port source and build instructions.
- `SHA256SUMS`: SHA-256 checksums for the VPK and source archive.

This release contains the native ONScripter-JH runtime and LiveArea resources. Game scripts, archives, translation files, font, and music are supplied separately from your own compatible copy.
